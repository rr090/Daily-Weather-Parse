# Weather Bot

Автоматический парсер погоды для 98 городов мира. GitHub Actions запускается раз в сутки, получает актуальные данные через [Open-Meteo API](https://open-meteo.com/) и сохраняет их в репозиторий. Отдельная страница на GitHub Pages показывает погоду в удобном виде на трёх языках.

## Что делает проект

- **Парсит погоду** для 98 городов: 8 немецких, 36 столиц Европы, 20 российских, 3 кавказских, 5 центральноазиатских, 3 азиатских, 5 североамериканских, 8 южноамериканских и 5 городов Океании.
- **Берёт данные с Open-Meteo** — бесплатный API без ключа. В одном пакетном запросе получает данные сразу по всем городам.
- **Сохраняет три файла**: полный JSON с текущей погодой и прогнозом на 7 дней, а также два CSV — с текущими условиями и с прогнозом, разбитые по месяцам.
- **Показывает погоду на веб-странице** с адаптивным меню, поиском, фильтром по регионам и переключением языков (DE / EN / RU).
- **Ссылается на шесть внешних сервисов** для каждого города: Meteoblue, Windy, Ventusky, Яндекс.Погода, Gismeteo, Weather Underground.

## Структура репозитория

```

.
├── .github/
│   └── workflows/
│       └── weather.yml       # Workflow GitHub Actions
├── cities.json               # Справочник городов (98 записей)
├── weather.py                # Скрипт парсинга
├── weather.json              # Последний снимок (обновляется автоматически)
├── weather_current_YYYY-MM.csv   # Текущая погода за месяц
└── weather_daily_YYYY-MM.csv     # Прогноз за месяц

```

Страница `index.html` лежит в отдельном репозитории GitHub Pages и тянет `weather.json` через `raw.githubusercontent.com`.

## Как это работает

1. **Триггер.** Cron `0 0 * * *` — каждый день в 00:00 UTC. Плюс возможность ручного запуска через `workflow_dispatch`.
2. **Скрипт.** `weather.py` читает `cities.json`, группирует города по 50 штук и делает пакетные запросы к Open-Meteo с параметром `timezone=auto`, чтобы каждый город получил своё местное время.
3. **Сохранение.** Результат пишется в `weather.json` в виде словаря `{ "berlin": { current, daily }, ... }`. Строки дописываются в CSV текущего месяца (`weather_current_2026-11.csv`, `weather_daily_2026-11.csv`).
4. **Коммит.** `stefanzweifel/git-auto-commit-action` коммитит обновлённые файлы от имени `github-actions[bot]`.

## Формат данных

`weather.json`:

```json
{
  "generated_at": "2026-11-21T07:05:00+00:00",
  "cities": {
    "berlin": {
      "city": { "name_ru": "Берлин", "lat": 52.52, "lon": 13.41, ... },
      "fetched_at": "2026-11-21T07:05:00+00:00",
      "current": {
        "temperature_2m": 9.2,
        "relative_humidity_2m": 78,
        "apparent_temperature": 7.1,
        "weather_code": 2,
        "wind_speed_10m": 15.8,
        ...
      },
      "daily": {
        "time": ["2026-11-21", "2026-11-22", ...],
        "temperature_2m_max": [11.4, 10.2, ...],
        "temperature_2m_min": [4.8, 3.9, ...],
        "sunrise": ["2026-11-21T07:34", ...],
        "sunset": ["2026-11-21T16:08", ...],
        "daylight_duration": [31020, 30840, ...],
        ...
      }
    }
  }
}
```

Поля в current: температура, влажность, ощущаемая температура, флаг дня/ночи, осадки (дождь, ливни, снег), код погоды, облачность, давление на уровне моря и на земле, скорость и направление ветра, порывы.

Поля в daily: код погоды, максимум/минимум/среднее за день, ощущаемые максимум и минимум, восход, закат, продолжительность светового дня и солнечного сияния, УФ-индекс (реальный и по чистому небу), осадки (сумма, дождь, ливни, снег, часы осадков, вероятности), ветер (максимум, порывы, преобладающее направление).

Расшифровка weather_code

Код по стандарту WMO — одна цифра вместо длинного текста.

Код Значение
0 Ясно
1–3 Преимущественно ясно / переменная облачность / пасмурно
45, 48 Туман
51–57 Морось (в том числе ледяная)
61–67 Дождь (в том числе ледяной)
71–77 Снег
80–82 Ливни
85–86 Снегопады
95–99 Гроза (с градом или без)

Справочник городов

cities.json — единственный источник правды. Для каждого города хранятся:

· id — уникальный код (berlin, paris, moscow, newyork).
· name_ru, name_en, name_de — названия на трёх языках.
· country_ru, country_en, country_de — названия страны на трёх языках.
· country_code — двухбуквенный код страны (DE, FR, RU).
· region — регион для группировки в меню (germany, europe, russia, caucasus, central_asia, asia, north_america, south_america, oceania).
· lat, lon — координаты.
· state — только для США (штат, нужен для ссылки Weather Underground).

Чтобы добавить город, достаточно дописать строку в cities.json. Код скрипта менять не нужно.

Веб-страница

Живёт отдельно на https://rr090.github.io/ и забирает данные по адресу:

```
https://raw.githubusercontent.com/rr090/Daily-Weather-Parse/main/weather.json
```

Что есть на странице:

· Меню справа сверху (гамбургер) — выезжает панель с аккордеоном по регионам.
· Поиск — фильтрует города по названию на трёх языках и по стране.
· Выбор региона — показать все города региона сразу.
· Выбор города — показать одну карточку и проскроллить к ней.
· Переключение языков DE / EN / RU, выбор сохраняется в localStorage.
· Карточка города: текущая температура, ощущаемая, иконка погоды, детали (влажность, облачность, ветер, порывы, давление, осадки) и прогноз на 7 дней с иконками, восходом/закатом и УФ-индексом.
· Шесть внешних ссылок на каждой карточке: Meteoblue, Windy, Ventusky, Яндекс.Погода, Gismeteo, Weather Underground. Все открываются в новой вкладке.

Запуск вручную

1. Открыть вкладку Actions в репозитории.
2. Выбрать workflow Daily Weather Parse.
3. Нажать Run workflow → Run workflow.

Ресурсы и лимиты

· GitHub Actions для публичных репозиториев — бесплатно и без ограничений по минутам. Для приватных — 2000 минут в месяц, из которых используется около 30.
· Open-Meteo — бесплатно до 10 000 запросов в день. Скрипт делает 2 запроса в сутки (по 50 городов каждый).
· Размер данных. weather.json для 98 городов с прогнозом на 7 дней — около 500–700 КБ. Каждый месячный CSV — 100–200 КБ. Git-история растёт медленно благодаря разбивке CSV по месяцам.

Требования

· Python 3.11 (устанавливается автоматически в workflow).
· Библиотека requests.
· Разрешение contents: write для GITHUB_TOKEN (прописано в weather.yml и включено в настройках репозитория).
